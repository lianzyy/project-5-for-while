Kalkulator Nilai Mahasiswa
Kalkulator Nilai Mahasiswa adalah program sederhana berbasis web yang dibuat menggunakan HTML, CSS, dan JavaScript. Program ini digunakan untuk menghitung nilai mahasiswa dari lima mata kuliah, mulai dari menghitung total nilai, rata-rata, menentukan predikat, hingga mengetahui status kelulusan.

Fitur program
- Memasukkan nama mahasiswa dan lima nilai mata kuliah.
- Memeriksa apakah data yang dimasukkan sudah benar.
- Menghitung total dan rata-rata nilai mahasiswa.
- Menentukan predikat nilai A, B, C, D, atau E menggunakan percabangan `if-else`.
- Menentukan status kelulusan mahasiswa.
- Menggunakan perulangan `for` untuk membaca dan menampilkan nilai.
- Menggunakan perulangan `while` untuk menghitung total nilai.

Teknologi yg digunakan
- HTML Membuat struktur halaman web.
- CSS Mengatur tampilan agar lebih rapi dan menarik.
- JavaScript Mengolah data, melakukan perhitungan, serta menjalankan percabangan dan perulangan.
  
Tujuan
Program ini dibuat untuk mempelajari penerapan percabangan dan perulangan dalam JavaScript dengan contoh yang sederhana dan mudah dipahami. Selain itu, program ini juga membantu memahami cara menghubungkan HTML, CSS, dan JavaScript dalam pembuatan aplikasi web.

Cara menjalankan
1. Download atau clone repository ini.
2. Buka folder program di Visual Studio Code.
3. Pastikan file `index.html`, `style.css`, dan `script.js` berada dalam satu folder.
4. Buka file `index.html` menggunakan browser.
5. Masukkan nama dan nilai mahasiswa, lalu klik tombol "Hitung Nilai" untuk melihat hasilnya.
